# 工具使用说明

工具签名通过 function calling 自动提供。本文件说明非显而易见的约束和用法。

## http_get — 网络请求

- 仅支持 GET 请求
- 响应内容截断至 3000 字符
- 不支持需要登录认证的页面
- 天气查询示例：`https://wttr.in/北京?lang=zh&format=3`

## exec_command — 执行命令

- 超时默认 30 秒
- 输出截断至 2000 字符
- 禁止执行危险命令（rm -rf、格式化、关机等）
- 仅用于本地安全操作

## remember / recall / forget — 长期记忆

- remember：保存用户偏好、姓名、习惯等持久事实
- recall：查看所有已保存的长期记忆
- forget：删除不再需要的记忆条目
- **不要**存储密码、证件号、银行卡等敏感信息

## search_history — 历史搜索

- 在完整对话日志中关键词搜索
- 返回最多 20 条匹配记录
- 适合查询「上次提到的...」类问题

## clear_session — 清除会话

- 清除指定会话的对话历史（短期+持久化）
- 长期记忆（MEMORY.md）不受影响
